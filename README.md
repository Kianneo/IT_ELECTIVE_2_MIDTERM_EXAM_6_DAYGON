# Package Pickup Monitoring System

## What It Does

- **User Accounts:** Public sign up and login pages. Package pages are protected with cookie authentication so only logged in users can manage records[cite: 1].
- **Package Tracking:** Complete CRUD setup to add, view, edit, and review package info[cite: 1].
- **Claim Handling:** Mark items as claimed to automatically record the timestamp and who picked[cite: 1].
- **Fast Search:** Search bar to filter items by tracking code, recipient name, or unit number[cite: 1].
- **Form Validation:** Form and server checks using ModelState to prevent missing or bad data[cite: 1].
