
## What It Does

- **User Accounts:** Public sign up and login pages Package pages are protected with cookie authentication so only logged in users can manage records
- **Package Tracking:** Complete CRUD setup to add, view, edit, and review package info
- **Claim Handling:** Mark items as claimed to automatically record the timestamp and who picked 
- **Fast Search:** Search bar to filter items by tracking code, recipient name, or unit number
- **Form Validation:** Form and server checks using ModelState to prevent missing or bad data
